Privacy policy

Last updated: 5 November 2026

The short version

This site does not collect any personal data. There are no accounts, no sign-ups, no forms and no adverts. It does not use cookies, and it doesn’t track or identify anyone.

It does count, anonymously, how many times each page is viewed, so we can see which tools are useful. This is explained below.

What is stored on your device

Your browser remembers a few things so they stay the same next time: settings such as your colour theme and course filter, your favourite tools, the tools you used recently, and your scores in the practice questions. These are kept in your browser's own storage (local storage) on your device. They are never sent anywhere and contain nothing personal. You can clear them at any time by clearing your browser's site data.

The site also saves a copy of its own pages in your browser, so it keeps working if the internet connection drops. Again, this stays on your device.

Links copied with "Copy link" store a simulation's set-up (such as a circuit) in the web address itself. Nothing is saved on a server.

Services this site relies on

Like every website, pages have to be delivered over the internet. Four outside services are involved, and they can see the basic technical details every web connection involves (such as your IP address and browser type):

  • GitHub Pages hosts the site. GitHub may keep server logs for security and to keep the service running. See the GitHub Privacy Statement.
  • Cloudflare Web Analytics counts page views (see below). See Cloudflare’s privacy policy.
  • cdnjs (run by Cloudflare) supplies the code that draws QR codes. It is only downloaded if you press Share. See Cloudflare’s privacy policy.
  • Google Fonts supplies the text fonts. Your browser downloads them from Google's servers. See the Google Fonts privacy FAQ.

This site doesn't receive, see or store any of that information. The only thing it sees is the anonymous page-view totals described below.

Counting page views

The site uses Cloudflare Web Analytics to count how many times each page and tool is viewed. It is designed to be privacy-friendly:

  • It does not use cookies, and it doesn’t store anything on your device.
  • It does not identify you, build a profile of you, or follow you across other websites.
  • It records only general details about each visit: which page was viewed, the website that linked to it, the type of browser and device, and the country.

We only ever see totals, such as “the Bonding tool was viewed 120 times this week”. We can’t see who visited or link a visit to a person. The counts are used only to decide which tools to improve and add.

Children

The site is designed for school students. Because no personal data is collected, there is nothing children need to provide, and nothing to share with anyone. The page-view counts are anonymous and don’t use cookies, so no permission or consent is needed to use the site.

Changes

If this ever changes (for example, if accounts or saving work online are added), this policy will be updated before that happens, and the date at the top will change.
